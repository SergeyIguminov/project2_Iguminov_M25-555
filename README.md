## Установка
### Требования:
- **Python** от 3.13;
- **Poetry** от 2.0.0 до 3.0.0;
- **Ruff** от 0.14.6;
- **Prompt** от 0.4.1 до 0.5.0
- **Prettytable** от 3.17.0 до 4.0.0

### Процесс установки:
Распакуйте проект в удобную директорию. Затем в терминале введите:
make install
или
poetry install

После успешной установки можно начать пользоваться:

make run
или
poetry run database


## Управление таблицами

### Доступные команды:

#### **Создание таблицы**
create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...
Допустимые типы данных для столбцов: str, int, float
При работе с другими типами программа выдаст ошибку.

#### **Просмотр таблиц**
list_tables

#### **Удаление таблицы**
drop_table <имя_таблицы>

### CRUD-операции

**Вставка значений**
insert into <имя_таблицы> values (<значение1>, <значение2>, ...) - создать запись.

**Прочтение записи**
select from <имя_таблицы> where <столбец> = <значение> - прочитать записи по условию.

**Прочтение всех записей в таблице**
select from <имя_таблицы> - прочитать все записи.

**Обновление записи**
> update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия> - обновить запись.

**Удаление записи**
> delete from <имя_таблицы> where <столбец> = <значение> - удалить запись.
